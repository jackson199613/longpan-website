# 龙盘 LP SeaSpark 官网首页（第二版）

外贸英文首页展示稿。纯静态页面，推送到 GitHub 后由 Netlify 自动部署。

- `index.html`：首页成品（由 `src/index.template.html` 生成，地图点阵数据已内嵌）
- `src/index.template.html`：首页源文件
- `preview/`：首页长图（电脑端、手机端）和首屏高清图，用于给客户看效果
- `netlify.toml`：Netlify 配置，无需构建，发布目录为仓库根目录
- `robots.txt`：允许搜索引擎和海外 AI 爬虫抓取

所有视觉（机组线稿、世界航线图、图标）都是代码绘制的原创图形，不依赖外部图片。
Logo 目前是占位标识，正式版换成客户的 SeaSpark 标志。
