# 龙盘 LP SeaSpark 官网首页（第四版：重工业风）

外贸英文首页展示稿。对标 Cummins、Caterpillar 官网的重工业视觉：深色钢板与水泥灰交替的大色块、窄体粗黑大写标题、切角按钮和图片、警示斜纹、等宽字体的参数标注。纯静态页面，推送到 GitHub 后由 Netlify 自动部署。

配色取自客户原有两个网站：

- SeaSpark Logo 蓝 `#2300A5`：顶栏和导航
- SeaSpark 蓝 `#00119F`（lpseaspark.com）：负荷测试面板、联系区等蓝色色块
- 富电康橙红 `#ED461C`（fudiankang.com）：强调色，按钮、编号、警示条
- 富电康钢蓝 `#1F394C` 系：深色区块底色

文件：

- `index.html`：首页
- `images/`：首页用图。机组、车间、工序、Logo 来自客户官网 lpseaspark.com；油田、海上平台、港口、电站、数据中心为 Unsplash 免费授权图片（Unsplash License，可商用）
- `preview/`：首页长图（电脑端、手机端），用于给客户看效果
- `netlify.toml`：Netlify 配置，无需构建，发布目录为仓库根目录
- `robots.txt`：允许搜索引擎和海外 AI 爬虫抓取

## 第五版：多页面升级（2026-11）

在第四版首页风格（重工业风）基础上扩展为多页面网站，图片和视频优先使用甲方提供的素材（升级网站资料、工厂图片视频两个文件夹），只对亮度、对比度、锐度做了轻度修图。

页面：

- `index.html`：首页。保留首屏第 1 张主图和开场动画；其余图片换成甲方实拍（车间、保税维修航拍、3616/3608 机组、电站项目等），新增项目案例板块，数据按甲方宣传片更正为 130,000 m²、300+ 员工
- `inventory.html`：现货机组。51 台（卡特、康明斯、MTU、MWM、颜巴赫、苏尔寿），按品牌、新旧、功率筛选，点开看大图和运行视频，可一键发 WhatsApp 询价。参数只取自文件夹名称
- `specs.html`：SS 系列技术参数表，来自《二手机组清单，技术参数.xlsx》，已去重并翻译成英文
- `cases.html`：7 个项目案例，来自《海南龙盘项目案例介绍.pdf》
- `about.html`：公司介绍、英文宣传片、四大业务、双服务基地、合作模式、证书（ISO 三证、营业执照）

文件：

- `css/site.css`：所有页面共用样式（原首页内联样式抽出 + 新组件）
- `images/c-*.jpg`：甲方实拍图（已修图）；`images/stock/<机组编号>/`：现货机组图，card.jpg 为列表封面
- `videos/`：厂区航拍循环视频、英文宣传片；`videos/stock/`：机组运行视频（每台一段，720p）
- 质保口径来自《再制造机器质保期限.docx》：再制造 1 年 / 1000 小时，二手机不质保
